## 🚀 About me

I'm a **Software Development Engineer at Swiggy** (since Sept 2024). I build and run backend systems where correctness matters because real money and credit decisions flow through them, handling millions of transactions a day.

In about two years I've worked across three domains:

| Domain | What I worked on |
| :-- | :-- |
| 💳 **Payments** | UPI, cards and wallet flows; Kafka-based reconciliation for stuck transactions; legacy-service migration; direct gateway integration; circuit-breaker tuning |
| 🏦 **Lending** | Built a consumer-lending stack from near-zero: consent APIs, application state machine, KYC auto-fill, e-sign/OTP, multi-lender integrations and lead routing |
| 🍽️ **Partner platform** | Permissioning with role-safety guarantees, finance-API hardening, LLM-powered support tooling, business-metrics observability |

**480+ merged PRs across 30+ production repositories.** I care about reliability, observability and alerts people actually act on.
